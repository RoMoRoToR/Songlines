# llm_collective — коллектив LLM-агентов с символической памятью

LLM-эксперименты для LLM-секций
[`papers/qrmc_aaai27/`](../../papers/qrmc_aaai27/),
полной версии и [`papers/semantic_warp/`](../../papers/semantic_warp/)
(волны W4/W6/W6-C): N=3 агента (llama3.1 через Ollama) с общей
символической памятью на текстовой навигации.

Ключевые находки:

- **Сырой обмен вредит:** против no-communication базлайна на
  идентичных раскладках success падает 2/3→1/3 (occupancy racing —
  феноменология грид-свипа воспроизводится на языке);
- **Warp Drive возвращает часть:** 0.333→0.417, rollback latency ≈ K;
  восстановление частичное — на LLM добавляются семантические потери
  (галлюцинации тегов), резервациями не лечатся;
- **Step-budget свип** (2 модели): непрозрачный коллапс 1.00→0.00
  резолвится в чистый C-отказ (Q=R=M=1, C=0) идентично для обеих
  моделей — структурный, не модельный диагноз.

Технически: `llm_backend.py` — обёртка Ollama (llama3.1, qwen3:4b;
think-off для qwen через `extra_body={"think": False}`); послойное
исполнение — LLM решает семантику (M-lock, take/put), локомоция —
детерминированный waypoint-примитив; LLM-петле нужен
exploration-ярус (bootstrap-проблема).

Данные: `tmp/llm_collective/`, `tmp/warp/w6_llm*`.
