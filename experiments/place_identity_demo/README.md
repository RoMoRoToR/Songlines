# place_identity_demo — демо тождества мест по смыслу

Демонстрация сопоставления мест **по смыслу**, а не по общей
координатной сетке — иллюстративный компаньон к секции «Place identity
from meaning» в
[`papers/collective_semantic_memory/`](../../papers/collective_semantic_memory/)
и к W7–W9 в [`papers/route_warp/`](../../papers/route_warp/).

Механика: локальные отпечатки-созвездия (семантические теги на
относительных смещениях tag@(dx,dy)), взаимно-уникальный матчинг,
восстановление сдвига/поворота кадров по совпавшим ориентирам.
Боевая реализация — `experiments/warp/semantic_identity.py`
(трансляция + SE(2)); здесь — минимальный самодостаточный пример.
