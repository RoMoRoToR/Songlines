## Ключевые числа S0

- (б) такты без общего якоря: **11/11 fail-open** (лок всегда, правильный
  никогда); с общим якорем — 1.0 correct → «тактов недостаточно» —
  измеренный факт: такты паразитируют на идентичности якоря.
- (а) σ+такты: покрытие 1.0, все переносы точные, 0 fail-open,
  **366 бит ≈ 6.4%** от снапшотов (5690 бит) при равной корректности.
- (г) σ без тактов: 0 переносов невиданной цели — рёбра необходимы.
