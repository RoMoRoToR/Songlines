# Переформулировки памяти: четыре линзы и функциональная таксономия

**Дата:** 2026-07-26
**Статус:** research reframing (дополнение к `FRONTIER_SONG_GRAMMAR_2026-07-25.md`)
**Задача:** не карта соответствий («куда в стеке ложится линза»), а переформулировка: что каждая линза **меняет в дизайне** — какие обязательства она накладывает, каким уже измеренным результатом подтверждается, какое регистрируемое предсказание порождает.

---

## 1. Четыре линзы

Формат каждой линзы: тезис → реализация в стеке → **дизайн-обязательства** → измеренный свидетель → регистрируемое предсказание.

### 1.1 Бихевиористская: память = изменённые диспозиции

**Тезис.** Хранилища нет; есть перестроенные склонности к действию. «Помнить место» = быть перестроенным местом, без обращения к репрезентациям.

**В стеке:** transition-статистики, trust-EMA — меняют поведение, не будучи «знанием о чём-то».

**Меняет в дизайне:**
1. Единица переноса между агентами — **диспозиция, а не факт**: легально обмениваться перестройками поведения без обмена контентом.
2. Абляция памяти = **заморозка диспозиций**, а не удаление записей: две разные операции, которые нельзя смешивать в экспериментах.
3. Оценка памяти — по поведенческим дельтам, а не по точности контента.

**Измеренный свидетель:** R3 — маршрут наследует безопасность свидетеля (0 vs 3.25 хитов при равном завершении): переносится именно диспозиция (как идти), а не декларативное знание. Trust-flip (W2, R2) — поведенческий выключатель при неизменном контенте памяти.

**Регистрируемое предсказание:** два агента с идентичным контентом памяти, но разными trust-EMA дают статистически различимые Q/R/M/C-профили — диссоциация контента и диспозиции.

### 1.2 Когнитивистская: память = хранилище с доступом

**Тезис.** Репрезентации, запись, извлечение. Это НЕ линза, которую надо преодолеть, — это линза, границы которой надо знать.

**В стеке:** place records, концепт-решётка (Galois), retrieval-контур. **Q/R/M/C измеряет ровно этот контур — и только его**: все четыре события заякорены на явном цикле query→retrieval→lock→completion.

**Меняет в дизайне:**
1. Граница измерителя становится явной: всё, что действует **вне запроса** (поле, диспозиции), для Q/R/M/C невидимо → фреймворку нужны парные **метрики диссоциации** (см. §1.4).
2. 91% candidate-generation starvation — диагноз когнитивистского контура, а не «памяти вообще»: лечить его можно и снаружи контура (рассказом, полем).
3. Модель синхронизации архивов — предельный случай этой линзы; она остаётся **бейзлайном** (плечо (в) Фазы 0), а не целью.

**Измеренный свидетель:** 91%/96.9% (generation vs ranking); learned-baseline MLP (0.59 < majority 0.81) — state features не заменяют накопленную структуру.

**Регистрируемое предсказание:** вмешательства вне контура не двигают P(R\*|Q\*), но двигают success — расщепление, которое видно только паре {success-only, Q/R/M/C} вместе.

### 1.3 Энактивистская: память разыгрывается, а не хранится

**Тезис.** Память — не извлечение следа, а повторное разыгрывание в сцеплении со средой (в т.ч. социальной). Знать = уметь исполнить.

**В стеке:** цикл «спеть → сопоставить → врастить»; fail-closed как отказ исполнять; каденция K.

**Меняет в дизайне:**
1. **Запрет глобального стора как инвариант архитектуры** (не оптимизация): коллективная память существует только в цикле обмена; песня — партитура, а не копия состояния; приёмник ре-граундит, а не реплицирует.
2. Критерий корректности — **исполнимость** (performability), не соответствие: валидный лок S0 — «дошёл по чужой партитуре», честный отказ — «не могу исполнить» (fail closed).
3. Каденция **конститутивна**, не гиперпараметр: остановка цикла обязана разрушать коллективную память по закону. Staleness — дизайн-обязательство энактивизма, а не инженерное удобство.

**Измеренный свидетель:** bottleneck shift M↔C по K (p<0.0001) — свойства «памяти» меняются от ритма исполнения; закон старения 6/6 hold-out; W6 — сырой обмен (копирование без контракта) снижает success 2/3→1/3.

**Регистрируемое предсказание:** «замороженная» песня (цикл остановлен) деградирует по ln-закону дальности; возобновление цикла восстанавливает пригодность без гистерезиса.

### 1.4 Бессознательное: направляет, не будучи доступным запросу

**Тезис.** Значительная часть памяти влияет на решения, не проходя через явный доступ, — и это не дефект, а отдельный режим работы с собственной функцией.

**В стеке:** семантическое поле Phase 4 (активации, диффузия, резервации байасят retrieval **до и вне** query) — почти буквальная реализация; варп-такси (51.2% собственных завершений warp-assisted при P(C\*|W\*)≈0).

**Меняет в дизайне:**
1. **Два маршрута доступа мерятся раздельно:** явный (через Q, гейтится φ/trust/staleness) и полевой (байасит исследование, admissibility-гейты НЕ проходит — контракт провенанса относится к коммитам, не к байасам).
2. Метрика диссоциации: **success-without-R\*** — успехи без события retrieval; systematic, а не шум.
3. Приватный остаток словаря (высокий s₁, низкий s₃) — **имплицитный слой коллектива**: не входит в песню, но улучшает индивидуальный success (предсказание P1.3 фронтира). «Бессознательное коллектива» = то, что механизм координации систематически не рассказывает.
4. Консолидация в простое = сон: selective consolidation между эпизодами, а не только на каденции.

**Измеренный свидетель:** такси-цепочки — имплицитная помощь, невидимая стратам P(C\*|W\*), найденная только контрфактическим маскированием (детерминированный повтор с масками) — методологический шаблон для измерения имплицитного вообще.

**Регистрируемое предсказание:** field-only агент (retrieval отключён, поле включено) превосходит blind по encounter rate при нуле R\*-событий.

## 2. Для чего агенты формируют память: таксономия с абляционной матрицей

«Память — не единый механизм» — операционализируется так: у каждой функции своя точка деградации на Q/R/M/C-цепи. Отключаешь функцию — рвётся предсказанная связка, и только она.

| Функция | Реализация в стеке | Абляция | Что деградирует | Статус |
|---|---|---|---|---|
| **Для-возврата** (вернуться к хорошему) | эпизодика, place records, transition-статистики | не консолидировать собственный опыт | **Q\*→R\***: candidate starvation; M→C в мирах с дорогим путём | **измерено**: 91% starvation = режим недонакопления; MLP-байзлайн не заменяет (0.59); R1 cliff |
| **Для-рассказа** (координировать) | обмен: снапшоты → песни (σ, e) | no-comm (first-class Independent runtime) | **R\* принимающей стороны на недосэмплированных ИМ тегах**; перенос невиданной цели невозможен | **частично измерено**: independent vs peer (12960 прогонов); S0: (г) 0 переносов невиданного без рёбер; остаток — P1.1 (Фаза 1) |
| **Для-доверия** (фильтровать чужое) | trust-EMA, staleness-гейт, conflict fusion | uniform trust / decay off | **C\*** через устаревшие и отравленные коммиты; «гонка за угасающей песней» | **измерено**: trust-flip обнуляет варп (W2) и маршруты (R2); «гейт, а не обмен» несёт выигрыш CSM; W6 — сырой обмен вредит |
| **Для-рассказа-имплицитно** (байасить, не утверждая) | семантическое поле Phase 4; приватный остаток словаря | поле off | success-without-R\* исчезает при неизменном Q/R/M/C-профиле | **не измерено** → Фаза 0b, предсказание §1.4 |

Три следствия:

1. **Разные функции — разные законы старения.** Диспозиции (trust-EMA) стареют иначе, чем факты (staleness-гейт), и иначе, чем словарь (W10: обеднение — безопасно). Единый decay — категориальная ошибка.
2. **Функции не сводимы друг к другу измерением:** каждая ломает свою связку. Это и есть операциональный ответ — не «память бывает разная» (слова), а «абляция функции i рвёт связку j(i), и матрица диагональна» (измерение).
3. **Недостающие ячейки** (полевая диссоциация; P1.1-gain на чужих тегах) регистрируются как **Фаза 0b** фронтира — три абляции × Q/R/M/C-профиль на CSM-бенчмарке, масштаб «минуты».

## 3. Связь с фронтиром

- Линзы 1.1/1.4 дают Фазе 0b два новых плеча (заморозка диспозиций ≠ удаление записей; field-only диссоциация).
- Линза 1.3 фиксирует инвариант всей программы: глобального стора не существует ни в одной фазе; каденция и staleness — конститутивные элементы, их «оптимизация в ноль» запрещена по построению.
- Линза 1.2 объясняет, почему фитнес Фазы 1 не включает Q/R/M/C: фреймворк меряет явный контур, а отбор должен быть свободен давить и на имплицитные маршруты.
- Критерий программы («экологическая пригодность вместо прямой верификации») зафиксирован в `FRONTIER_SONG_GRAMMAR`, §2а.
