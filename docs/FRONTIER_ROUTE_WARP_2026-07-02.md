# Фронтир: Route-warp — передача пути, а не места

**Дата:** 2026-07-02
**Статус:** research design (следующий фронтир после Semantic Warp)
**Зависимости:** `experiments/warp/` (W0–W6), `peer_memory/`, songline_drive graph edges. Warp-слой не меняется — расширяется определение φ на рёбра.

---

## 1. Vision одним абзацем

В semantic warp (W0–W6) варпится **знание о местах**: broadcast несёт снапшот концептов (центроиды, профили, support), но НЕ рёбра графа — не переходы, не маршруты. Путник получает «где вода» и строит путь сам. Но songline в первоисточнике — это не точка, это **последовательность**: песня и есть маршрут. Route-warp формализует передачу пути: событие, при котором агент проходит **связный фрагмент чужой траектории**, ни разу не наблюдав его сам. В открытых гридах W0–W5 эффект невидим по построению — путь дёшев (манхэттен почти всегда оптимален). Нужны миры, где путь дорогой: лабиринты, hazard-коридоры, узкие проходы. Тогда place-warp и route-warp предсказуемо расходятся: place-warp говорит «куда», route-warp — «как», и разница измерима той же provenance-машинерией.

## 2. Формальное ядро

### 2.1 Провенанс рёбер

Рёбра локального графа уже существуют (songline_drive: `SharedConceptEdge`, transition statistics в AgentMemory). Расширение broadcast-снапшота: поле `edges = [(cid_a, cid_b, traversals, last_tick)]` — только СВОИ пройденные переходы (foreign рёбра не ретранслируются, как и в place-снапшоте). Провенанс ребра π(e) наследуется от отправителя.

### 2.2 Route-foreignness

Для пути P = (v₀ → v₁ → … → v_n), которым планировщик ведёт агента:

```
φ_route(P) = Σ_{e ∈ P, π(e) ≠ self} w(e) · len(e)  /  Σ_{e ∈ P} w(e) · len(e)
```

— доля чужой массы в рёбрах пути, взвешенная длиной. Строгий route-warp: **RW\* := агент прошёл связный подпуть ≥ L рёбер с φ_route = 1.0** (ни одно ребро не наблюдал сам). Замер в момент коммита пути (freezing rule §3.1 семантик-варпа переносится дословно: собственное прохождение не размывает φ_route).

### 2.3 Отношение к place-warp

Place-warp — вырожденный случай: путь длины 0 (только цель чужая). Иерархия событий: W\* (чужая цель) ⊂ RW\*-lite (чужая цель + частично чужой путь) ⊂ strict RW\* (чужая цель + весь путь чужой). Стратификация P(C\*|·) по (φ_place, φ_route) — двумерная провенанс-плоскость вместо одномерной оси.

## 3. Главное предсказание (фальсифицируемое)

**В мирах с дорогим путём route-warp даёт то, что place-warp дать не может.** Операционально, три руки на одном лабиринте (ablation):

1. **no-warp** (independent) — базлайн;
2. **place-warp** (текущий peer: только концепты) — агент знает, ГДЕ цель, но путь ищет сам;
3. **route-warp** (peer + edge-снапшоты) — агент знает и ГДЕ, и КАК.

Предсказания (регистрируются до прогонов, в духе W2/W5):

- **R1.** В открытом гриде (стоимость пути ≈ манхэттен): t_succ(place) ≈ t_succ(route) — рёбра не добавляют ничего; честный negative-control.
- **R2.** В лабиринте с detour-фактором D = (реальный путь / манхэттен) ≥ 2: выигрыш route против place растёт с D; при D → 1 исчезает. Кривая gain(D) — аналог закона дальности, но по оси сложности мира.
  - **[Ревизия по итогам R1, 2026-07-02]:** эмпирически gain(D) — не наклон, а **ступень**: place-warp коллапсирует бинарно на первой стене (success 1.0 при D=1.00 → 0.0 при D=1.38; lock-притяжение к стене — ловушка-цикл). Правильная формулировка для R2+: cliff-detection (порог D коллапса place) + success-rate ablation; метрика negative-control при D=1 — длина пути в клетках (разрыв 0.0 точно), не тики (поворотная экономия даёт +4.7).
- **R3.** Закон дальности для рёбер: ребро выпадает из планирования при том же trust·e^{−α·age} < τ → **длинные чужие маршруты рвутся в середине** при старении evidence: предсказуемая точка разрыва пути = ребро с минимальным weight. Патология «песня оборвалась на полуслове» — измерима как RW\*-lock с C\*=0 и позицией разрыва, предсказанной заранее.
- **R4.** Hazard-версия: маршрут через hazard-поле, где неверный шаг наказуем. Place-warp агент несёт hazard-риск разведки, route-warp — нет: разрыв стратифицируется по n_hazard_hits, не только по t_succ.

## 4. Мир

`multiagent_env` расширяется генератором лабиринтов (стены по recursive backtracker / hazard-коридоры), параметр — целевой detour-фактор D ∈ {1 (open), 2, 4}. Планировщик: текущий plan_action не умеет обходить стены (tier-1 идёт по прямой) — нужен waypoint-follower по чужому пути: приоритет рёберного маршрута над манхэттен-наведением, fallback на exploration при разрыве. Это единственное место, где меняется планировщик, и оно честно объявляется (route-warp невозможен без потребителя маршрутов; сравнение архитектур остаётся при одном и том же новом планировщике во всех трёх руках).

## 5. Экспериментальная программа

| Этап | Что | Объём |
|---|---|---|
| **R0** | Edge-снапшоты в peer broadcast + φ_route инструментация + maze-генератор | ~250 LOC, 2–3 дня |
| **R1** | Ablation no/place/route × D ∈ {1,2,4} × 20 сидов, регистрация R1–R2 | ~150 LOC, 2 дня |
| **R2** | Разрыв маршрута по старению (R3): witness-traveler на лабиринте, предсказание точки разрыва | ~100 LOC, 1–2 дня |
| **R3** | Hazard-стратификация (R4) + фигуры | ~100 LOC, 1–2 дня |

Бюджет: ~600 LOC, ~1.5 недели, compute $0 (гриды).

## 6. Риски

| Риск | Mitigation |
|---|---|
| Планировщик-follower решает всё сам (route-warp станет тривиальным) | follower работает только по рёбрам с weight ≥ τ — та же гейт-механика; ablation с выключенным follower |
| Maze-генератор даёт несравнимые миры между руками | один сид = один лабиринт для всех трёх рук (paired design, как маски W1) |
| Рёберные снапшоты раздувают трафик | логировать payload size; это само по себе метрика (стоимость песни) |
| «Это просто передача плана» (рецензент) | нет: передаётся пройденный опыт (traversals), не план; φ_route меряет провенанс опыта; freezing rule + закон разрыва — те же измерительные ходы, что дали 6/6 hold-out |

## 7. Definition of done

- [x] RW\*-события в логах с φ_route (R0: strict RW\*, φ_route=1.0, 45 рёбер, C\*=1)

- [x] Предсказанная и подтверждённая точка разрыва маршрута по старению (R2: 110/110 режимов, все 21 разрыв с ошибкой 0 рёбер, trust-flip для маршрутов)
