# Songlines: финальная таблица вердиктов серии

**Дата свода:** 2026-08-03. Все вердикты — из зарегистрированных предсказаний (записаны на диск до прогонов); честные провалы приведены с механизмами. PASS/FAIL — как в `*_results.json`; «FAIL✻» = честный провал регистрации, механизм которого сам является результатом.

Дисциплина серии: предсказания регистрируются до исполнения, провалы публикуются с механизмами, сильнейшие результаты — точные совпадения с замкнутыми предсказаниями. Test-сиды интеграционной волны (100+) никогда не использовались для настройки.
