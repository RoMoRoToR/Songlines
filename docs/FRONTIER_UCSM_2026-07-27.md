# Фронтир: UCSM — Utility-Certified Songline Memory

**Дата:** 2026-07-27

## 1. Ключевая мысль

**Полезность и простота аналогии — две независимые оси.** Нельзя решать, что запоминать, по одному скаляру (similarity / novelty / importance / reward):

| Полезность | Аналогия | Операция памяти |
|---|---|---|
| высокая | простая | **MERGE** — ассимилировать в существующую схему |
| высокая | простая, но противоречит решению схемы | **EXCEPTION** — контрпример, не перезапись |
| высокая | сложная | **NEW_SCHEMA** — новое понятие |
| низкая | простая | **REPEAT** — обновить статистику, записи нет |
| низкая | сложная | **DROP** |

Пятая ячейка (EXCEPTION) — защита от ложной генерализации: полезное, противоречащее схеме, нельзя ни слить, ни выбросить.

## 2. Формальное ядро

**Контрфактическая маргинальная полезность** (обобщение source-masked replay из Semantic Warp с «чужое свидетельство on/off» до «это воспоминание on/off»):

```
U_{i,ι}(m | M) = cost_i(M, ι) − cost_i(M ∪ {m}, ι)
```

— полезность контекстна (по агенту i и намерению ι) и маргинальна (относительно текущей памяти M): **дубликат имеет U = 0 по построению**, без всякой similarity-эвристики. Командная версия добавляет штрафы: −λ_col·collisions − λ_comm·communication − λ_err·false transfer.

**Стоимость аналогии** между эпизодом e и схемой s через отображение φ:

```
C_analog(e,s) = L(φ) + λ_d·D_decision(e,s) + λ_a·Defect(φ);   A(e,s) = exp(−C_analog)
```

Реализация Этапа 1: L = масса куплетов вне сигнатурного LCS; share = LCS/min(len); D_decision = манхэттен между сквозными смещениями двух песен (куда они в итоге ПОСЫЛАЮТ идущего). Похожесть описаний и совпадение решений — разные вещи, и D_decision ловит именно второе (ср. decision distortion в rate-distortion рамке «Remember the Decision, Not the Description»).

**Единица памяти — условная программа, не факт:**

```
m = (G_m — граф/песня, C_m — условия применимости, E_m — ожидаемые эффекты,
     U_m — профиль полезности ПО РОЛЯМ, Φ_m — известные аналогии,
     P_m — провенанс/эпизоды, F_m — известные отказы и контрпримеры)
```

**Utility certificate** при передаче: Cert(m) = (conditions, ΔV, uncertainty, evidence ids, analogy map, failure cases). Приёмник НЕ обязан верить оценке отправителя — он переносит песню через собственное φ_ij и пересчитывает свою U (в U1 проверено: receiver с другой позиции пересчитывает U > 0 сам). Для гетерогенных тел это принципиально: U_slow(m) > 0 при U_fast(m) < 0 — воспоминание хранит функцию полезности, а не один вес.

**Landmark должен возникать, а не распознаваться:**

```
S_landmark(f) = E[U_team | f использован для alignment] − λ₁L(f) − λ₂Redundancy(f) − λ₃C_obs(f)
```

GradCAM/attention/MI — только генераторы кандидатов; статус присваивается **причинной проверкой**: исчезает ли координационная полезность при удалении признака из песни (абляционный тест — машинерия W10 уже это умеет на уровне классов).

## 3. Четырёхслойная архитектура длинной памяти

1. **Immutable episodic store** — исходные эпизоды не переписываются (урок «Useful Memories Become Faulty…»: непрерывная перезапись сначала помогает, потом вредит; первичные свидетельства — якорь реконсолидации).
2. **Analogical schema graph** — схемы/песни/ландмарки/исключения (консолидация по двухосевой матрице).
3. **Procedural layer** — частые схемы → policy fragments.
4. **Coordination layer** — не факты мира, а социальные правила: reservations, роли, доверие, условия передачи.

В активный контекст LLM попадает не история, а: подходящие схемы + минимальные supporting episodes + актуальные исключения + текущий координационный контракт. Задача — не хранить токены, а **реконструировать релевантное прошлое с доказательствами**.

## 4. Related work (позиционирование; сверить ссылки перед подачей)

- *Remember the Decision, Not the Description* (rate-distortion, decision distortion) — ближайшая по духу; наше отличие: координационные последствия + гетерогенные агенты + сертификаты.
- Generative Agents (recency/relevance/importance + reflections) — importance эвристичен, у нас — измеренная контрфактическая полезность.
- MemRL — обучаемая Q-полезность **использования** записанного; у нас полезность управляет **формированием**.
- Mem-α — RL по операциям построения памяти, но QA-задача, не координация.
- MemGAS — многогранулярность; TrustMem — coverage/preservation/faithfulness при консолидации (наш EXCEPTION + immutable store бьют в ту же проблему с другой стороны).
- Ничья работа (по видимому) не объединяет: структурную аналогию + причинную полезность + гетерогенных агентов + координационные последствия + возникновение landmarks/песен + сохранение первичных свидетельств. Это и есть конструкция.

## 5. Этапы

### Этап 1 — детерминированный прототип: СДЕЛАНО (U1, 2026-07-27, 4/4 PASS)

`ucsm.py` + `exp_u1_ucsm_smoke.py`: 8 валидных миров × 5 кандидатов (по ячейке матрицы + конфликт), два одноосевых бейзлайна на том же потоке. Registered v1 провалилась на двух дефектах КОНСТРУКЦИИ (не модели), задокументировано в `u1_registered.json`; v2:

| | UCSM | similarity-only | utility-only |
|---|---|---|---|
| операции | ровно [NEW, REPEAT, NEW, DROP, EXCEPTION] ×8 | junk инкорпорирован, A′ перезаписал A | нет структуры исключений |
| размер памяти | 3 (vs append-all 5) | 3, но коррумпирована | 3 |
| cost на мире A | **12.25**, first-try | 62.6, phantom-first | 24.0, phantom-first (recency) |
| cost на варианте A′ | **20.5** (exception) | — | — |
| A′ без exception | 70.4 | | |

Измеренные тезисы: дубликаты бесплатны по построению (U=0); similarity — не критерий консолидации (хранит мусор + молча коррумпирует); EXCEPTION бьёт и перезапись, и recency; сертификат пересчитывается приёмником.

### Этап 2 — обучаемый memory controller: СДЕЛАНО (U2 v2, 2026-07-27)

`exp_u2_bandit.py`: LinUCB, состояние x = (U, share, D, novelty, размер памяти), действия = 5 операций матрицы, награда = измеренное Δcost на пробе {мир кандидата, мир ближайшей схемы} − налог на биты. Итоги (24 train-стрима, независимая eval-батарея):

- **U2.1 PASS:** выученная политика **78.1** < ручная матрица 83.5 (−6.5%) < random 105.9 (−26%). Матрица консолидации выучивается из координационного фидбека — и обучение находит политику лучше спроектированной.
- **U2.2 честный FAIL (3/5 классов) с механизмом:** v1 показала, что бандит восстанавливает структуру с точностью до reward-эквивалентности ({store, replace, no-op}; DROP-ячейка 40/43); v2 с независимой батареей и support-последствиями оставила контекстно-зависимые эквивалентности (MERGE дубликата ≡ REPEAT; REPEAT мусора ≡ DROP) и одно **прибыльное принципиальное отклонение: hand=MERGE → NEW_SCHEMA** — контроллер сам открыл immutable-store принцип «не перезаписывай, храни обе версии с приоритетом по support» (слой 1 архитектуры §3; ср. TrustMem и «Useful Memories Become Faulty…»). Оба цикла регистраций задокументированы в `u2_registered.json`.

Полный meta-RL (решения о записи влияют через много эпизодов) — после U7-развязки.

### Этап 3 — эволюция грамматики песен: СДЕЛАНО (U3, 2026-07-27, 2/2 PASS)

`exp_u3_evolution.py`: ES (30 поколений × 16 особей) по θ = (gap, share_thr, d_thr, u_thr, vmax), фитнес = стоимость на свежих картах + λ·биты. Итоги:

- **U3.1 PASS:** эволюционированный геном на holdout эквивалентен ручному (fitness 105.86 vs 105.43, +0.4% — в пределах регистрации 2%).
- **U3.2 PASS:** **бюджет отобрался сам** — vmax=10 (конечный) без регрессии стоимости (+0.06%): ограниченная рациональность как результат селекции, не дизайна.
- **Незарегистрированное, но красивое:** селекция независимо сошлась к окрестности спроектированных порогов — share_thr 0.74→0.46 (ручной 0.4), d_thr 3.9 (ручной 3) — конструктивные константы матрицы лежат у аттрактора отбора (родственно предсказанию P1.4 родительского фронтира «закон как аттрактор»). Отличия от дизайна: gap→1 (куплеты плотнее) и u_thr→1.3 (хранить больше маргинального) при конечном vmax — «больше, но короче».

Следующий уровень (за пределами U3): контроллер выбирает, какой признак — landmark, когда сливать песни, кому передавать (= полный π_mem родительского фронтира).

## 6. Решающий эксперимент (7 плеч) и вычислительная стратегия

Predator–Prey, два кооперативных агента (быстрый-хрупкий / медленный-живучий), частично совпадающие награды, частичная наблюдаемость; **тест — новые карты с теми же функциональными структурами, но другими внешними признаками.** Плечи: raw long context / vector similarity / recency-importance-relevance / текущая CSM / utility-only / analogy-only / **UCSM (utility+analogy+coordination certificate)**. Метрики: success на новых картах, Q/R/M/C, объём памяти и активного контекста, ложные объединения, cross-agent transfer gain, collision rate, число и абляционная полезность возникших landmarks, сохранение различий ролей, качество после 10/100/1000 эпизодов.

**Вердикты U7 (2026-07-27, 12 сидов × все длины): все четыре регистрации — честные FAIL, с механизмами.**

| | e10 frag | e100 frag | e1000 frag | биты e1000 |
|---|---|---|---|---|
| raw | 128.9 | **53.3** | **139.8** | 339 453 |
| utility | 130.5 | 53.6 | 144.6 | 162 107 |
| ucsm | 132.8 | 60.8 | 145.2 | **153 774** |
| vector | 161.1 | 214.7 | 232.1 | 186 843 |
| rir | 190.7 | 225.4 | 250.1 | 339 453 |

- **U7.1/U7.3 FAIL:** UCSM в пределах ~5–14% от raw по стоимости, но не доминирует; на e1000 у всех песенных армов phantom rate ≈ 0.95 — **фантомный каскад из накопленных конфликтов**. Диагноз: это проблема STALENESS, не консолидации — ни один арм не имел age-гейта, а это территория уже доказанного закона age_max. Единственная добродетель raw — его newest-first и есть грубая эвристика свежести.
- **U7.2 FAIL:** биты UCSM ×8 на декаду (почти линейно) — открытый стрим (30% новых семей) не даёт сублинейности без кросс-семейной абстракции; консолидация ограничивает рост внутри семьи (2.2× меньше raw, 34× меньше snapshot), но не против притока нового мира.
- **U7.4 FAIL:** parent-first и newest-first фантомят одинаково на смешанной батарее.
- **Устойчивое через все масштабы:** структурная память (identity+beats: raw/utility/analogy/ucsm) бьёт мейнстримные эвристики (vector/rir/snapshot) в 1.7–4.5×; UCSM — минимум бит среди песенных армов везде. Тезис выжил в уточнённой форме: *консолидация покупает биты, а не успех, когда транспорт fail-closed; успех на длинном горизонте решает staleness*.
- **U7b (готово): staleness-диагноз подтверждён на среднем горизонте, у избыточности нашлась остаточная ценность на длинном.** Арм `ucsm_recent` (та же консолидация + newest-first потребление): на **e100 — PASS** (52.0/67.9 против raw 53.6/68.9 на обеих ролях за **54% его бит**; сам порядок потребления закрыл весь разрыв UCSM 61.6→52.0). На **e1000 — FAIL** с механизмом: отставание ~3% (145.4 vs 140.9, 3/8 сидов), фантомный каскад насыщается у всех (rate 0.96–0.97) — избыточность raw имеет остаточную ценность при дрейфе внешности (старые варианты песни якорятся там, где новейшая не находит куплетов). Итоговая формула: **консолидация + свежесть = стоимость raw за половину бит на средних горизонтах; на экстремальных горизонтах консолидация меняет ~3% успеха на 2.2× экономию бит.** Следующий рычаг — не порядок, а настоящий age_max-гейт и кросс-семейные схемы.

**Доделка разрывов (2026-07-27, вторая волна):**

- **E1 — emergent landmarks (сделано, локально):** замкнутый цикл propose→ablate→measure→promote реализован (`exp_e1_landmark_emergence.py`). Кандидаты: контент-классы + производный `degree` + нарочно вредная `parity` (frame-вариантная). Итог: цикл **причинно обнаружил вред parity** (Δ=−0.67; её присутствие давало score 0.33 через отказы — fail-closed выдержал, 0 fail-open за все раунды) и дошёл до минимального словаря score 1.0. **E1.2 PASS; E1.1 честный FAIL с открытием:** итоговый словарь — {wall, **void**}: void несёт 0 консенсусной массы (W10), но каузально несущ как **анти-алиасинговый страж** — при обеднении словаря до {wall} границы-двойники начинают алиаситься с полосой, и void их различает. Мораль: **каузальная абляция ≠ атрибуция массы; ценность признака неаддитивна и зависит от остального словаря.** v1-дефекты (parity от истинных координат; одновременный прунинг взаимозаменяемых) задокументированы.
- **U7c — trust×staleness в потреблении (готово): робастная роль закрыта, регистрация — честный FAIL.** `ucsm_stale` (age-decay + дискретный trust-flip дискредитированного родителя) на e1000: robust 214.2 ≤ raw 214.3 (закрыто), fragile 142.2 vs 140.9 (−0.9% — разрыв сокращён втрое против −3% у одной свежести). Строгая регистрация «обе роли» провалена честно: остаточная ценность избыточности при дрейфе внешности переживает и гейт. **Лестница композиции измерена: консолидация −14% → +свежесть −3% → +trust-flip −0.9%.**
- **X1 — кросс-семейный кодбук (готово): PASS.** Рост бит 7.91×/декаду < 8.42× у плоского кодека; абсолютная экономия растёт с масштабом (−10% @e100 → −16% @e1000, 129.4k vs 154k) — кросс-семейные мотивы существуют и монетизируются. Сублинейность приближена, не достигнута: полная схемная абстракция (слоты/роли) — открытая половина.
- **L1/L1b — LLM end-to-end цикл (СДЕЛАНО, 2026-07-27):** полный цикл замкнут на живых моделях (локальная Ollama + GPU sphinx, Qwen HF offline). Регистрации: L1.1 память необходима (0.0 без памяти — все модели); L1.2 реконструкция ≥ транскрипта за ≤15–30% payload (факт: 6–12%); L1.3 исключения работают в контексте. **llama3.1-8B: 6/6 PASS** (raw 0.42→0.08 с ростом истории, цепочки 0.17→0.00; ucsm 1.0 всюду); **Qwen2.5-3B: длинные истории 3/3 PASS** (короткий транскрипт читает на 1.0, 12-эпизодные цепочки роняют raw до 0.375; ucsm 1.0 за 6.1%). qwen3:4b — потолок способности ниже задачи (цепочка supersedes не решается ни в одном плече при любом бюджете мышления) — исключён честно. Вывод: **сырой транскрипт воспроизводит фантомный каскад U7 в пространстве промпта (ломает именно устаревшее большинство, не длина); реконструированный schema graph = staleness-гейт промпт-пространства.** 7B-джобы в очереди за занятыми nike/kali — бонус.
- **Третий эшелон (СДЕЛАНО, 2026-07-28, G1/S1/M1 на sphinx):**
  - **G1 graph-matching:** NW-выравнивание с частичным узловым сходством + реляционный дефект → −24% схем и бит против LCS при cost ±5% и phantom +0.012; G1.1 формальный near-miss (0.76 vs 0.75), G1.2 PASS. Путь к сублинейности открыт.
  - **M1 meta-RL, 2/2 PASS:** ES с терминальной-только наградой бьёт и шейпленного бандита (−97.95 vs −99.69), и ручную матрицу (−99.95); exception store-класс 91% — третье независимое переоткрытие immutable-принципа.
  - **S1 социальный процесс — сильнейший честный негатив программы:** на 300 эпизодах при глобальном дрейфе миров НЕЗАВИСИМОСТЬ бьёт всякий обмен (frag 148 vs 170; rob 171 vs 238); приёмники копят 741 чужую схему против 221, время трансляции ≠ время мира. 3/4 регистраций FAIL; S1.3 PASS (резервации зануляют дубликаты бесплатно). Вывод = центральный закон серии на уровне формирования: **обмен без staleness-контракта на мировых часах чисто вреден** (социальная форма W6). Недостающий механизм — family-state версионирование + age_max на мировом времени.
  - **S2 world-clock staleness (СДЕЛАНО, 2026-07-29): необходим, но недостаточен.** Версионирование референта + гейт на обоих концах + версия-гossip в метаданных: улучшает каждое коммуницирующее плечо (rob 238→220, frag 170→163), резервации компонуются (S2.3 PASS), но реверс S1 не реверсируется — independent бьёт cert_wc на всех 12 сидах, память не сжимается (688 vs 708). Возвращено ~27% штрафа. **Два негатива зажали проблему: ни message-time (S1), ни world-time (S2) фильтрация не делают обмен нетто-полезным на горизонте. Остаточный механизм невременной — кросс-семейный алиасинг от объёма чужого. Следующий рубеж: admission control — допуск чужого только по продемонстрированной полезности на собственных визитах (сертификат = свидетельство; свидетельство — не допустимое доказательство).** Грабля v1: MERGE сохранял старую версию → свежеслитое гейтилось.
  - **S3 admission control (СДЕЛАНО, 2026-07-29): 4/4 PASS — СОЦИАЛЬНЫЙ РУБЕЖ ЗАКРЫТ.** Карантин всего чужого + валидация на месте при визите (replay полезности на реальном мире собственной ролью; «measured, not told») + world-clock + резервации: adm_util бьёт independent на каждом сиде и обеих ролях (frag 118 vs 148 −20%, rob 134 vs 171 −21%); монотонная лестница механизма 162/220 → 136/169 → 118/134; допущенная память 233 vs 688 (0.34×, 592 мусорных сертификата в карантине); резервации: 0 дубликатов за +0.6%. **Социальная лестница программы измерена целиком: S1 (обмен без контрактов вреден) → S2 (часы мира необходимы, недостаточны) → S3 (свидетельство не доказательство — допуск по полезности на своих визитах закрывает рубеж).**
  - **Интеграционная волна (2026-07-30, «один честный метод»):**
    - **Runtime v1** (`runtime.py`): единый тип записи m=(G,C,E,U,P,T,R,F), все механизмы — конфиг-флаги; полный wire-кодек (сертификат 64 + провенанс 48 + время/версия 32 + резервация 24 бита).
    - **R1 — интеграционный чеклист: PASS 10/10** — все десять механизмов рецензента срабатывают в ОДНОМ прогоне одного рантайма.
    - **I1 — интеграционный бенчмарк на sphinx** (25 задач): 8 главных армов + 9 абляций × 12 test-сидов (100+, никогда не использованных для настройки) × e300 × 2 интента (вода/отдых) × приватные кадры; noise-ось {0, 0.1, 0.2}; N-ось {4, 6, 8}. Registered H1 (композиция), H2 (шум: fail-open<0.05 при 10%), H3 (масштаб по N). Стандартные метрики: success/fail-open/refusal/hazard hits/дубликаты/wire+memory биты/латентность.
    - **UE1 — utility-оцениватель без оракула** (на sphinx): ridge на runtime-доступных признаках; смоук: Spearman 0.93, sign 0.86, деградация контроллера на Û в допуске.
    - **N1 — FN×FP свип идентичности** (на sphinx, 5×5 × 30 сидов, margin 0.75 registered).
    - **Терминология исправлена в статьях:** «full SE(2)» → дискретная подгруппа ℤ²⋊C₄; «inherits safety» → «preserves the witness's measured risk profile within the validated route prefix»; «Emergent landmarks» → «Causally promoted landmarks»; том пересобран.
  - **Закрывающая волна (2026-07-31, три дыры acceptance-теста):**
    - **Дыра 1 (fail-open<1%) ЗАКРЫТА:** консенсус ≥2 якорей + loop-closure вшит в Runtime; **N1v2: fail-open 0.000 по всей сетке до 20%×20%** (было до 0.21), покрытие 0.88→0.58 — safety ценой покрытия, честно.
    - **Дыра 3a (равные бюджеты) ЗАКРЫТА сильнее плана:** B1 — full@1×кап 119.8/124.5 бьёт raw@1× (158.7/199.9), **raw не догоняет даже при 4× бюджета** (159/201) — беда raw не в объёме, а в отсутствии консолидации; сильнее исходной планки «2× экономия».
    - **Дыра 3b (adversarial provenance) ЗАКРЫТА с находкой:** P1 — full деградирует +1.2% под отравителем, порядок обороны держится (P1.2 PASS); главный «противник» коллективной памяти — энтропия мира, не злоумышленник (незащищённый арм уже насыщен фантомами, яд маргинален); admission поглощает и ложь, и стейл. origin-bound приём блокирует отмывание за 0 цены.
    - **Дыра 2 (второй субстрат) ЗАКРЫТА частично:** C1 континуальный мир (вещественные позиции, джиттер, мягкий матчер констелляций, унимодальная кластеризация якорей + центроид — тот же Runtime); эффект переносится (full 244.7/74.7 < independent 256.8/79.6), НО safety требует continuous-калибровки: консенсус=2 даёт fo 0.79, **консенсус=4 (songline_safe)** на dev-транспорте → wrong-place 0.000, НО на социальном e300 консенсус сам недостаточен. **C1.4 ЗАКРЫТА трёхслойной обороной** (каждый слой ловит пропущенное): консенсус≥3 (0.79→0.15) + commit-top1 (→0.04) + **prefix-verify** (путник проходит первые 5 куплетов, сверяет наблюдения с песней; чужесемейный фантом расходится с местностью → отказ до коммита) → **fail-open 0.0014 на test-сидах, 554×, 10/12 ровно 0, success даже растёт**. Prefix = named-рецензентом «safe prefix» как жёсткий гейт; позволяет снизить консенсус вернув покрытие. C1.1/C1.3 PASS (full 245/71 < raw 257/101 < indep на e150). raw@e300 континуум интрактабелен O(E²) — находка против raw-контекста.
    - **L1 7B добит:** Qwen2.5-7B raw 1.0→0.75 на длинных конфликтах, ucsm 1.0 за 13% payload — монотонно по способности (llama-8B 0.08 / 3B 0.375 / 7B 0.75), реконструкция держит 1.0 у всех.
  - Остаётся: continuous SE(2) вариант 2 (метрический registration), DeMem/Mage/OAS-бейзлайны на их субстратах, LLM-социальный процесс, открытое порождение признаков.

**Кластер (КТ ИТМО, sphinx):**
- локально (минуты): U1-класс смоуки, Этап-1 абляции, Фаза 0 song grammar;
- **sphinx**: 7 плеч × 3 масштаба эпизодов × ≥12 сидов (CPU-жирный sweep — обычные ноды, без GPU), Этап 2 bandit-обучение, и все LLM-плечи (raw long context / vector memory) — GPU-ноды, `gpu-env cu124`; памятка из прошлых прогонов: 7B-модели гнать на nike/kali, выставлять TMPDIR, греть LLM-кэш заранее;
- дизайн под кластер: каждый арм — отдельный процесс с сид-шардированием (`--seeds a..b`), результаты в jsonl, агрегатор отдельно — чтобы sbatch-массив ложился без переделок.

**Registered-гипотеза программы:** лучшая коллективная долговременная память не максимизирует сходство воспоминаний и не делает представления агентов одинаковыми — она **минимизирует сложность переноса полезных различий** между локальными картинами мира. (Совместно с functional-complementarity критерием родительского фронтира: конвергенция представлений при том же выигрыше = FAIL.)

**Формулировка будущей работы:** формирование памяти = ограниченная задача выбора между сохранением эпизода, аналогической ассимиляцией, созданием новой схемы, исключением и забыванием, где выбор определяется не описательной значимостью наблюдения, а его контрфактической полезностью для будущих индивидуальных и коллективных решений, скорректированной на сложность структурного переноса.

## 7. Риски

| Риск | Mitigation |
|---|---|
| Контрфактический replay дорог при больших M | маргинальность: replay только против top-k ближайших схем; Этап 2 учит аппроксиматор U |
| «Полезность» переобучается на карту | U меряется и на свежих картах (как фитнес родительского фронтира) |
| EXCEPTION-взрыв (всё — исключение) | D_THR + бюджет исключений на схему; сплит схемы при ≥k исключениях (по TrustMem-критериям coverage/preservation) |
| Единицы стоимости несравнимы (урок U1-v1) | одна валюта cost для guided/blind/фантомов, регистрируется до прогонов |
| LCS-аналогия слишком груба | Этап 2: graph matching с ролями/отношениями; категорно — частичный функтор (задел: alignment-морфизмы CSM) |
