# Song Grammar / UCSM: онтогенез запоминаемого

Статья №5 серии (6 стр. EN/RU). **Тезис:** что запоминать — решает не
описательная заметность, а контрфактическая полезность для будущих
решений, скорректированная на стоимость структурного переноса; и
правило решения, и грамматика под ним — выучиваемые и
эволюционируемые объекты.

## Ключевые результаты

- **U1 (4/4 PASS):** двухосевая матрица (utility × analogy) с
  операцией EXCEPTION; дубликаты бесплатны по построению; сходство —
  не критерий консолидации (12.3 vs 62.6 шага против перезаписи).
- **U2:** LinUCB выучивает матрицу из координационного фидбека и
  обыгрывает проектировщика (78.1 < 83.5 < random 105.9); его
  отклонение — «append, не overwrite» — переоткрытый immutable store.
- **U3 (2/2 PASS):** эволюция отбирает конечный бюджет vmax=10 и
  сходится к окрестности ручных порогов — константы у аттрактора.
- **U7/U7b (4 честных FAIL + PASS@e100):** структурная память бьёт
  мейнстрим в 1.7–4.5×; консолидация покупает биты (154k vs 339k vs
  5.2M), свежесть — успех; длинный горизонт — staleness-каскад
  (территория закона age_max).
