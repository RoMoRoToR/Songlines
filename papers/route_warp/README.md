# The Song, Not the Pin: Route Transfer and Meaning-Based Place Identity in Collective Memory

Companion-статья №2 (9 стр.). **Тезис:** переносимая единица
коллективной памяти — не «пин» (координата места), а «песня» (маршрут
с провенансом): перенос места бинарно обрывается на первой стене, а
перенос маршрута наследует и completion, и безопасность свидетеля — и
рвётся по предсказуемому закону старения.

## Ключевые результаты

- **R0–R1. Обрыв, а не наклон:** place-warp коллапсирует на первой
  стене (success 1.0 при D=1.00 → 0.0 при D=1.38) и при D≥1.38 хуже
  слепого поиска; route-warp — 20/20 при всех детурах (строгий RW\*,
  φ_route=1.0).
- **R2. Закон разрыва:** последовательный штамп рёбер свидетелем →
  путник гонится за угасающим следом; предиктор с точностью до ребра —
  110/110 режимов, все mid-route разрывы на предсказанном индексе
  (ошибка 0); trust-flip обнуляет коммиты.
- **R3. Hazard-стратификация:** маршрут наследует безопасность
  свидетеля (0 хитов vs 3.25 у place, 28.7 у blind); оси независимы
  (стены→completion, hazard'ы→safety); обрыв песни возвращает риск.
- **W7–W9. Тождество мест по смыслу:** отпечатки-созвездия
  tag@(dx,dy) + взаимно-уникальный матчинг; координатный baseline
  fails **open**, семантика fails **closed**; SE(2) (4 гипотезы
  поворота, доминирование ≥2×) — 80/80 точных восстановлений; закон
  дальности (breakpoints 20/14/9) воспроизводится без единой общей
  координаты. Corner-trap: границы мира 180°-симметричны → void-only
  отпечатки исключены (точность 0.159→1.000).
- **W10. Абляция словаря ориентиров (4/4 PASS):** обеднение алфавита Σ
  вплоть до одного класса тегов стоит покрытия (recovery 1.00→0.83),
  но не корректности — 0 fail-open из 252 ячеек; атрибуция массы
  матчинга hazard 0.56 / wall 0.44 / void 0.00. Явно введены два уровня
  «того же самого»: семантический предикат vs entity correspondence;
  ориентир = роль, а не тип клетки.
- **S0. Анатомия песни (4/4 PASS):** узлы несут идентичность, рёбра —
  перенос. Чисто реляционная песня (σ+такты, ноль глобальных координат)
  переносит невиданную цель точно за **6.4% бит** снапшота; одни такты —
  11/11 fail-open при рассогласовании якорей (такты паразитируют на
  идентичности якоря); одни сигнатуры — 0 переносов невиданного.
