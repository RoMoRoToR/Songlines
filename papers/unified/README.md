# Songlines: The Unified Series — монография-омнибус

Один документ вместо пяти статей — для навигации по всей программе
без переключения между файлами. **89 стр. EN / 90 стр. RU**, единая
библиография (72 источника), сквозное оглавление, кросс-ссылки
внутри частей сохранены (все метки автоматически префиксованы).

| Часть | Источник | Что внутри |
|---|---|---|
| I | `../qrmc_measurement_framework/` | протокол Q/R/M/C, 5 классов систем, диагноз 91% candidate generation |
| II | `../semantic_warp/` | φ-провенанс, W0–W6, закон дистанции, Warp Drive, LLM |
| III | `../route_warp/` | R0–R3, тождество мест W7–W10, анатомия песни S0 |
| IV | `../collective_semantic_memory/` | merge/trust/staleness, третий режим M×C, категорная рамка, фазовая диаграмма |
| V | `../song_grammar_ucsm/` | онтогенез памяти: двухосевая матрица UCSM, U1–U3, 7-арм кампания, staleness-диагноз |

**`symbolic_memory` не включена телом** — это исторический предок,
расщепившийся на части I и IV; каждый её эксперимент присутствует в
них в уточнённом виде (дублировать ~30 стр. того же текста — значит
вернуть путаницу, ради устранения которой том и собран). Линия
наследования описана в разделе «How to read this volume».

## Сборка (генерируется, не редактируется руками!)

`songlines_unified*.tex` — **сгенерированные файлы**. Источник истины
— четыре статьи + `preamble*.tex`/`front*.tex` + `build_unified.py`.
После любой правки исходных статей пересобрать:

```bash
python3 build_unified.py      # EN
python3 build_unified.py ru   # RU
pdflatex songlines_unified.tex     # ×3
pdflatex songlines_unified_ru.tex  # ×3
```

Скрипт: вырезает преамбулы/титулы, префиксует все метки `pN:`,
превращает аннотации статей в «Part abstract», конвертирует
`\appendix` в видимый разделитель приложений части, сливает и
дедуплицирует библиографии, выбрасывает NeurIPS-чеклисты.

Оригинальные четыре статьи остаются каноническими для подач; том —
рабочий документ программы.
