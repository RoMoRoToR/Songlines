# 02 - Semantic / Symbolic Memory

This folder contains the memory substrate used by the semantic navigation
stack.

## Main Files

- `songline_drive/symbolic_memory.py` - symbolic records and retrieval-facing
  memory structures.
- `songline_drive/graph_memory.py` - graph/place memory.
- `songline_drive/semantic_field.py` - semantic field representation.
- `songline_drive/collective_memory.py` - collective memory layer.
- `songline_drive/concept_recall.py` - concept recall helpers.
- `songline_drive/scene_tokenizer.py` and `scene_encoder.py` - observation to
  symbolic/semantic representation.
- `experiments/collective_semantic_memory/csm_memory.py` - standalone
  collective semantic memory experiment module.

## Original Locations

These files were copied from `songline_drive/` and
`experiments/collective_semantic_memory/`.
